Publishing Signals and Custom Data

How to publish a signal — or any custom data — to a HiveQ topic with the data driver, prove it landed, and then consume it from a backtest or a realtime LiveSim run. Going from backtest to LiveSim takes no code changes at all — same strategy, same callback; the platform converts the backtest's data sources into live subscriptions for you. The worked example is a signal called hiveq_signal_v1_test, but nothing here is specific to it.
